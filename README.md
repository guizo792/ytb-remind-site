# Remind Me Later: website

The home page, help page and privacy policy for the **Remind Me Later** browser extension, which sets timed reminders on YouTube videos and Shorts.

- Home: <https://guizo792.github.io/ytb-remind-site/>
- Help: <https://guizo792.github.io/ytb-remind-site/help.html>
- Privacy policy: <https://guizo792.github.io/ytb-remind-site/privacy.html>
- Questions or feedback: the Reviews tab of the extension's Chrome Web Store page.

This repository holds only these pages. The home page is generated from the extension's welcome page.

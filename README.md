# Remind Me Later: support and privacy pages

The help page and privacy policy for the **Remind Me Later** browser extension, which sets timed reminders on YouTube videos and Shorts.

- Help and support: <https://guizo792.github.io/ytb-remind-site/>
- Privacy policy: <https://guizo792.github.io/ytb-remind-site/privacy.html>
- Report a problem: use this repository's Issues tab. Issues are public, so please don't include personal information.

This repository holds only these pages.
